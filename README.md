## 🤝 Contributing

We welcome contributions from the community! Whether you're fixing bugs, adding features, or improving documentation, your help is appreciated.

### How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button at the top right of this repository
   - Clone your forked repository to your local machine:
     ```bash
     git clone https://github.com/YOUR-USERNAME/website.git
     cd website
     ```

2. **Create a Branch**
   - Create a new branch for your feature or bug fix:
     ```bash
     git checkout -b feature/your-feature-name
     ```
   - Use descriptive branch names like:
     - `feature/add-navigation`
     - `fix/responsive-layout`
     - `docs/update-readme`

3. **Make Your Changes**
   - Write clean, readable code
   - Follow the existing code style and conventions
   - Test your changes thoroughly
   - Update documentation if necessary

4. **Commit Your Changes**
   - Write clear and meaningful commit messages:
     ```bash
     git add .
     git commit -m "Add: Brief description of your changes"
     ```
   - Use prefixes like `Add:`, `Fix:`, `Update:`, `Remove:` for clarity

5. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Submit a Pull Request**
   - Go to the original repository on GitHub
   - Click "New Pull Request"
   - Select your fork and branch
   - Provide a clear title and description of your changes
   - Link any related issues

### 📋 Contribution Guidelines

#### Code Standards
- **HTML**: Use semantic HTML5 elements, proper indentation
- **CSS**: Follow BEM naming convention, organize properties logically
- **JavaScript**: Use ES6+ features, add comments for complex logic
- **General**: Keep code DRY (Don't Repeat Yourself)

#### What We're Looking For
- 🐛 **Bug Fixes**: Help us squash bugs
- ✨ **New Features**: Add functionality that enhances the website
- 📱 **Responsive Design**: Improve mobile and tablet experience
- ♿ **Accessibility**: Make the website more accessible to all users
- 📝 **Documentation**: Improve README, add code comments
- 🎨 **UI/UX Improvements**: Enhance the visual design and user experience
- ⚡ **Performance**: Optimize loading times and efficiency
- 🧪 **Tests**: Add test coverage

#### Pull Request Checklist
Before submitting your PR, ensure:
- [ ] Code follows the project's style guidelines
- [ ] Self-review of your code completed
- [ ] Comments added for complex sections
- [ ] Documentation updated if needed
- [ ] No console errors or warnings
- [ ] Tested on different browsers (Chrome, Firefox, Safari, Edge)
- [ ] Responsive design checked on mobile devices

### 🚫 What to Avoid
- Don't commit directly to the main branch
- Avoid large, unfocused pull requests (keep them small and specific)
- Don't include unnecessary files (node_modules, .DS_Store, etc.)
- No offensive or inappropriate content
